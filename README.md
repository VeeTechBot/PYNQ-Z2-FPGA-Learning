# PYNQ-Z2 FPGA Learning

This repository documents my learning and implementation journey in Digital Design, Verilog HDL, RTL Design and FPGA development using the PYNQ-Z2 development board.

## Development Environment
- FPGA Board: PYNQ-Z2
- FPGA: Xilinx Zynq-7000 (XC7Z020)
- IDE: AMD Vivado 2025.2
- HDL: Verilog
- Simulator: Vivado Simulator (XSim)

## Learning Roadmap

1. Verilog Fundamentals
2. Combinational Logic Design
3. Sequential Logic Design
4. Arithmetic Circuit Design
5. Finite State Machines
6. Communication Protocols
7. AXI Interfaces and Custom IP Development
8. FPGA-based Spiking Neural Network Accelerators

## Objective

To develop practical skills in RTL design, functional verification, FPGA implementation and hardware acceleration.
